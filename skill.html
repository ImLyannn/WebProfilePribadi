Oleh Brilliant

Logic

Kemampuan berpikir logis dan memecahkan masalah.

Logic

  • Pengalaman: tugas PKL dan project mandiri
  • Dipelajari: konsep JavaScript dan perhitungan
  • Contoh nyata: memperbaiki prompt gambar produk

  • Menganalisis masalah

    Saat hasil gambar produk tidak sesuai dengan gambar asli, saya menganalisis prompt dan memperbaikinya sampai hasilnya sesuai.

  • Mencari jalan lain

    Jika gambar produk tidak ditemukan di internet, saya mencarinya lewat kode barang pada katalog dan database perusahaan.

  • Belajar konsep dan perhitungan

    Lewat Gold Clicker, saya mulai belajar konsep JavaScript dan perhitungan di dalam game.

Skill · Rasa ingin tahu

Oleh Brilliant

Rasa ingin tahu

Keinginan mempelajari sesuatu, eksplorasi, dan proses belajar.

Rasa ingin tahu

  • Pengalaman: menggali informasi di waktu luang
  • Sedang dipelajari: membuat buku dan membuat lagu
  • Contoh nyata: Cosmic Sandbox dan Calyan Web

  • Tidak tenang jika tidak menggali

    Saat ada waktu luang, rasanya hampa jika saya tidak menggali informasi, bahkan tentang hal yang mungkin tampak kurang penting. Walaupun jurusan saya RPL, tiba-tiba saya ingin membuat buku atau membuat lagu.

  • Menghadapi rintangan

    Dalam proses itu saya sering menemui kesulitan: tidak tahu cara memulai, cara menginstal aplikasi, cara mengubah suara, atau fungsi sebuah fitur.

  • Terlihat di project

    Cosmic Sandbox saya buat untuk memahami konsep luar angkasa, dan Calyan Web untuk mempelajari komposisi website seperti teknik 60-30-10.

Skill · Introspeksi diri

Oleh Brilliant

Introspeksi diri

Melihat kembali diri, mengevaluasi perkembangan, memahami kelebihan dan kekurangan.

Introspeksi diri

  • Pengalaman: mencatat dan menulis evaluasi diri
  • Dievaluasi: sifat egois, malas, membandingkan diri
  • Contoh nyata: doomscrolling setelah membuka aplikasi

  • Mencatat evaluasi

    Di malam atau siang hari, saya mencatat dan menulis hal-hal pada diri saya yang perlu diperbaiki.

  • Kebiasaan yang ingin saya perbaiki

    Saya menyadari masih ada sifat egois, dan kadang bermalas-malasan setelah sekali membuka aplikasi hingga terjebak doomscrolling.

  • Membandingkan diri dengan orang lain

    Saya masih terlalu sering membandingkan diri dengan orang lain. Saya menyadari kebiasaan ini dapat memunculkan rasa iri dan dorongan berbuat curang.
