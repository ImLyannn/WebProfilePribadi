Perkenalan singkat dan cerita perjalanan PKL saya.

Perjalanan saya

Saya Brilliant Almighty Nimbuzz Dafolky, siswa kelas XI Rekayasa Perangkat Lunak di SMK TI Bali Global Denpasar. Saya melaksanakan PKL di JPT Retailindo dan JPT Groserindo, Denpasar, pada 24 Juli sampai 21 Desember 2026. Di sana saya mengerjakan tugas seperti melengkapi gambar produk pada website perusahaan dengan bantuan AI (lebih dari 10.000 SKU hingga laporan disusun), membuat suara pengumuman dengan ElevenLabs, membuat wallpaper karyawan, serta mengerjakan tugas Git, GitHub, dan pengenalan Frontend.

Selama PKL saya juga belajar membuat prompt yang jelas, dasar Microsoft Word dan Excel, serta memilih tools AI yang sesuai. Di luar tugas perusahaan, saya mengerjakan project web dan game sebagai latihan mandiri.
